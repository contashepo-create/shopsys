# تاريخ جزاء الموظف

نموذج تسجيل الخصم يعرض تاريخ اليوم وتقويماً للماضي؛ يحفظ تاريخ الجزاء في السجل ووقت التسجيل الفعلي مستقلاً. لا ينشأ قيد عند التسجيل؛ يتحقق الأثر المحاسبي عند استقطاعه بالمسير. تُفحص صلاحية الموظف والفرع وتاريخ الفترة، ويُرفض المستقبل وما يسبق جزاء أو استقطاعاً أو عفواً أو قيد مسير مسجلاً، أو سجلات مبهمة، فلا يُقلب ترتيب التخصيص. تسجيل القسيمة التي تستقطع جزاءً مؤرخاً يُحرس أيضاً. العفو يبقى حدثاً ممهوراً بوقت فعلي وليس تاريخ الجزاء.

استُخدم قفل الترحيل مع إعادة تحميل وبصمة وتحذير عند تعذر تأكيد الحفظ؛ بقية الكُتّاب لا يستعملون كلهم القفل. لا تُصلح هذه الحراسة قسائم أو استقطاعات تاريخية بلا أدلة تخصيص، ولا تثبت وقوع الجزاء خارج التطبيق، ولا تمنع كل تعارض مع المسارات القديمة. يلزم فحص شامل قبل اعتماد الماضي في بقية الرواتب.

التحقق: 35 اختباراً موجهاً للسلف والجزاءات والمحافظ والرواتب، وأنواع التطبيق والاختبارات وlint والمصفوفة 43/43. تضمن التعديل أيضاً معالجة تحذير lint في معاينة مسودة المحافظ باستخدام effect؛ تشغيل CI السابق `42598268754` فشل في lint قبل هذا الإصلاح، ولا يُعد نجاحاً للنسخة الجديدة.
