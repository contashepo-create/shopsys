# خطة فواتير البيع والشراء المتقدمة

## الهدف
محرران مستقلان عن الكاشير، متناسقان بصرياً، يدعمان المسودة والاعتماد والترحيل والتحصيل، ويحافظان على SQLite/Electron وOffline-first. صفحة فواتير المبيعات الحالية تبقى للسجل، ويضاف منها زر «فاتورة مبيعات جديدة». ويضاف المقابل للمشتريات.

## أنماط الإدخال
- مبسط: العميل/المورد، البنود، الخصم، الضريبة، الدفع.
- قياسي: المخازن، الشروط، العناوين، المرفقات، الرسوم، المندوب.
- تكلفة وربحية: داخلي وبصلاحية؛ التكلفة والهامش والمصروفات والعمولات، ولا يطبع للعميل.
- متقدم: مشروع/عقد/مركز تكلفة/عملة/أمر بيع أو شراء/إذن تسليم أو استلام/أقساط ودفعات مقدمة.

## المخازن
مخزن الرأس هو الافتراضي لكل سطر. تغيير الرأس يحدث السطور غير المعدلة يدوياً فقط. كل سطر يحتفظ بـwarehouseSource: default|manual. عند نقص الرصيد: منع الترحيل إذا كان السالب ممنوعاً، أو تحذير يوضح الرصيد المتوقع إذا كان مسموحاً، مع اقتراح مخزن بديل. يعاد الفحص داخل Repository لحظة الترحيل.

## إجماليات البيع
إجمالي البنود ← خصومات السطور ← الخصم العام ← صافي البنود ← إضافات العميل غير الخاضعة والخاضعة ← الوعاء الضريبي ← الضريبة ← التقريب ← صافي إجمالي العميل ← دفعات سابقة ← المحصل الآن ← المتبقي. الإضافة غير خاضعة افتراضياً، ويمكن تحديد المعالجة لكل إضافة.

## المصروفات الداخلية
قسم قابل للطي لا يظهر في مستند العميل/المورد. لكل مصروف: النوع والوصف والمبلغ والطرف والحساب ومركز التكلفة/المشروع، مدفوع الآن أو مستحق لاحقاً، وسيلة الدفع، الضريبة، وهل يدخل في الربحية، وفي الشراء هل يحمل على المخزون أم مصروف فترة. البيع: يخفض ربح الفاتورة ولا يزيد إجمالي العميل أو ضريبة المخرجات. الشراء: المصروف المحمل يوزع بالقيمة/الكمية/الوزن/الحجم/التساوي/يدوي ويحدث landed cost والمتوسط المرجح؛ مصروف الفترة لا يرفع المخزون.

## العمولات
ثابتة أو نسبة من الإجمالي/الصافي/الإيراد قبل الضريبة/الربح، حسب السطر أو الشرائح، وتقسيم بين موظفين. الاستحقاق عند الترحيل أو التحصيل أو تدريجياً. القيد: مصروف عمولات / عمولات مستحقة، والصرف يغلق الاستحقاق. المرتجع يعكس غير المصروف نسبياً أو ينشئ تسوية موظف إن صُرف.

## مشتريات متقدمة
المورد ورقمه الضريبي ورقم فاتورته، أمر شراء وإذن استلام، كميات مستلمة/مرفوضة، تشغيلات وصلاحيات وسيريالات، خصم وضريبة مدخلات، عملة، مخزن كل سطر، مصروفات مورد وجهات أخرى، استحقاقات متعددة، مطابقة ثلاثية اختيارية. الحالات: مسودة، بانتظار الاستلام، استلام جزئي، مستلمة، مرحّلة، مدفوعة جزئياً/كلياً، متأخرة، مرتجعة.

## الطباعة
زر واحد «طباعة ▾» مع طباعة سريعة بآخر قالب: A4/A5/حراري/ضريبي/مختصر/خدمات/توريد وتركيب/تصدير ثنائي اللغة/بدون أسعار/إذن تسليم أو استلام/PDF. كشف التكلفة داخلي وبصلاحية. لا تطبع التكلفة أو الربح أو العمولة أو المصروفات الداخلية أو الموافقات أو الحسابات للعميل.

## الذرية والربط
عند الترحيل تحفظ في معاملة واحدة: المستند، القيد، المخزون والتشغيلات والسيريالات، التحصيل والماكينة/الشيك، المصروفات والاستحقاقات، العمولات، المشاريع ومراكز التكلفة، المرفقات وسجل التدقيق. ترتبط بكشوف الأطراف وأعمار الديون والضرائب والربحية والتقارير وNASQ والطباعة والنسخ الاحتياطي.

## مراحل التنفيذ
1. نواة الأنماط والإضافات والمصروفات والربحية وسياسات المخزن والضريبة.
2. محرر المبيعات المتقدم والمسودات والتحصيل المختلط والعمولات.
3. محرر المشتريات المتقدم والمطابقة والاستلام والتكلفة المحملة.
4. Repository ذري وربط كل الأقسام والمرتجعات والاستحقاقات وسندات الصرف.
5. قوالب الطباعة والصلاحيات وتقارير الربحية واختبارات قبول المستخدم.
