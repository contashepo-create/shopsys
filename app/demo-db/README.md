# قاعدة البيانات التجريبية — وضع التطوير فقط

ملف SQLite حقيقي يعيش مع كود المشروع: **`app/demo-db/demo.sqlite`**.
يحتوي بيانات جاهزة لأربعة أنشطة مختلفة، ولكل نشاط بياناته المستقلة:
أصناف متعددة الخواص · عملاء · موردون · **مخازن متعددة** · **فروع متعددة** ·
**خزائن وبنوك ومحافظ إلكترونية تابعة لبنوكها** · **ماكينات دفع** ·
**فواتير بيع وشراء**.

> لا تدخل هذه البيانات نسخة الإنتاج إطلاقاً: واجهة القراءة/الكتابة إضافةُ Vite
> تعمل في `serve` فقط، وكل كود الواجهة محروس بـ`import.meta.env.DEV`.

## كيف تجرّب نشاطاً

1. `npm run dev`
2. اضغط زر **«بيانات تجريبية»** أسفل يسار الشاشة.
3. اختر النشاط ⇐ **«جرّب هذا النشاط»**. الانتقال إلى نشاط آخر يمسح بيانات السابق
   تلقائياً ثم يحمّل الجديد (لا اختلاط بين الأنشطة).

## كيف تعدّل البيانات

| الطريقة | الخطوات |
| --- | --- |
| من داخل التطبيق | عدّل الأصناف/العملاء… ثم **«حفظ التعديلات في القاعدة»** — تُكتب في `demo.sqlite` فوراً |
| بأي أداة SQLite | افتح `app/demo-db/demo.sqlite` بـ`sqlite3` أو DB Browser وعدّل الجداول مباشرة |
| من ملف البذور | عدّل `seed.data.mjs` ثم `npm run demo:build` (يعيد بناء القاعدة من الصفر) |
| تراجع | زر **«إعادة الضبط»** في اللوحة = إعادة بناء من `seed.data.mjs` |

```bash
npm run demo:build                 # إعادة بناء القاعدة من ملف البذور
sqlite3 app/demo-db/demo.sqlite    # تصفّح/تعديل مباشر
```

## البنية

- `schema.sql` — الجداول الثلاثة عشر (كلها تحمل عمود `activity`).
- `seed.data.mjs` — البيانات المقروءة القابلة للتعديل (مصدر البناء).
- `build.mjs` — يبني `demo.sqlite` من المخطط + البذور.
- `vitePlugin.mjs` — واجهة `/__demo/*` لوضع التطوير (قراءة · كتابة · إعادة بناء).
- المبالغ كلها **أعداد صحيحة بالقروش** (`*_minor`) التزاماً بقاعدة المشروع.

التحميل داخل التطبيق يمر بالإجراءات الرسمية (`postSale` / `postPurchase` /
`setOpeningBalance`)، فتُبنى القيود المحاسبية والمخزون بصدق بدل حقن حالة صامتة.
