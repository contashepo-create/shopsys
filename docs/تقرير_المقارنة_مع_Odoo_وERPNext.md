# تدقيق وظيفي شامل: «تَحَكَّم» مقابل Odoo وERPNext (أمر التعديل)

التاريخ: 2026-09-15 — يغطي كل ملفات الأنشطة المفعلة، مقارنةً بوحدات Odoo 17 وERPNext v15 القياسية.
المنهج: لكل نشاط — الوحدات المتاحة، النماذج، الروابط المحاسبية؛ ثم فجوات مصنفة:
✅ متكافئ أو أفضل للسوق المستهدف · 🟡 فجوة جزئية (مقبولة أو مجدولة) · 🔴 فجوة مؤثرة (مرشحة للتنفيذ).

## 1) الأساس المشترك (كل الأنشطة)
| القدرة | Odoo/ERPNext | تَحَكَّم | الحكم |
|---|---|---|---|
| دفتر أستاذ مزدوج القيد بقيود آلية لكل مستند | ✔ | ✔ (قيود متوازنة بنيوياً + ربط مستند↔قيد) | ✅ |
| شجرة حسابات + ميزان مراجعة + قائمة دخل | ✔ | ✔ | ✅ |
| متوسط مرجح متحرك للتكلفة + مصاريف شراء موزعة (Landed Cost) | ✔ | ✔ (قيمة/كمية لكل مصروف) | ✅ |
| عملاء/موردون بكشوف حساب | ✔ | ✔ + تحصيل FIFO بمطابقة اختيارية | ✅ |
| خزائن/بنوك متعددة + شيكات | ✔ | ✔ | ✅ |
| صلاحيات مستخدمين | ✔ | ✔ (المالك محمي بنيوياً) | ✅ |
| موافقات متسلسلة على الإجراءات الحرجة | ✔ (Studio/Workflow) | ✔ (حتى 6 مستويات، اعتماد يُستهلك) | ✅ |
| سجل تدقيق حركات المخزون | ✔ | ✔ (stockMoves للصرف؛ البيع/الشراء عبر القيود) | 🟡 توسعة stockMoves لكل الحركات لاحقاً |
| عملات متعددة في نفس الدفتر | ✔ | ✘ (عملة واحدة من بلد التأسيس) | 🟡 مقبولة للسوق المستهدف حالياً |
| ميزانية عمومية كتقرير مستقل | ✔ | جزئي (ميزان مراجعة مصنف) | 🟡 |
| مراكز تكلفة عامة عبر كل القيود | ✔ | للمشاريع فقط (BOQ كمراكز) | 🟡 |

## 2) لكل نشاط
### المقاولات 🏗️ — الأعمق بعد أوامر التعديل
✅ مشاريع/مستخلصات بمحتجزات، BOQ بموازنات، EVM بتنبيهات، أوامر تغيير، دفعات مقدمة (عميل وباطن)، مقاولو باطن باستقطاعات آلية (محتجز/ضريبة استقطاع/استرداد)، خطابات ضمان، يوميات مرنة (مشروع/تشغيل عام)، أذون صرف مواد بمتوسط مرجح، WIP، عُهد مواقع.
🟡 مقابل Odoo Construction (طرف ثالث): جدولة زمنية (Gantt) غير موجودة — خارج نطاق محاسبي.

### التجزئة (سوبر ماركت/ملابس/موبايلات/قطع غيار/أجهزة) 🛒
✅ POS سريع، دفعات وصلاحيات، سيريال/IMEI وضمان، مصفوفة لون×مقاس، وحدات متعددة، قوائم أسعار بشرائح، أقساط، ورديات، جرد.
🟡 ولاء نقاط العملاء (Odoo Loyalty) — غير مطلوب من المالك.
🔴 لا يوجد حالياً: طلبات شراء (Purchase Orders) قبل الفاتورة — Odoo يفصل أمر الشراء عن الفاتورة؛ حالياً الفاتورة مباشرة. مرشح تنفيذ عند طلب المالك.

### المطاعم 🍽️
✅ وصفات BOM بخصم خامات آلي، إنتاج مسبق، بيع سريع.
🟡 شاشة مطبخ KDS وطاولات (Odoo POS Restaurant) — تشغيلي غير محاسبي.

### الصاغة 💍
✅ سعر جرام يومي بالعيار، مصنعية منفصلة، كسر FIFO — أعمق من Odoo القياسي (لا وحدة صاغة أصلية فيه).

### إيجار المعدات 🚜
✅ عقود يومية/بالساعة/بالعداد، صيانة وقائية بالعداد، ربحية كل معدة، مشغلون.
🟡 حجز مسبق بتقويم (Odoo Rental) — مرشح لاحقاً.

### اللوجستيات 🚚
✅ نقلات بمصاريف وربحية، أسطول، مستحقات سائقين وتسوياتها.
🟡 تتبع GPS — خارج النطاق.

### المعمل والعيادة 🔬🦷
✅ فحوصات بنطاقات مرجعية، عمولات محيلين، تأمين بمطالبات وتسويات، خطط علاج بجلسات.
(ERPNext Healthcare يكافئها في النطاق المحاسبي.)

### معرض السيارات 🚗
✅ كل سيارة مركز تكلفة (تجهيزات ترسمل)، بيع أمانة بعمولة، إيجار.

### الصيدلية 💊
✅ تشغيلة وصلاحية إلزامية، تأمين.
🟡 توافق GS1 للباركود الدوائي — مرشح لاحقاً.

## 3) خلاصة الفجوات المرشحة للتنفيذ (بأولوية)
1. 🔴 أوامر شراء PO منفصلة عن فاتورة الشراء (دورة: طلب ← استلام ← فاتورة).
2. 🟡 توسعة سجل stockMoves ليشمل بيع/شراء/جرد/تحويلات (حالياً الصرف للمشاريع فقط).
3. 🟡 ميزانية عمومية كتقرير مستقل بتبويب قياسي.
4. 🟡 مراكز تكلفة عامة (أقسام/فروع) على مستوى القيد.
5. 🟡 حجز معدات بتقويم + KDS مطاعم + ولاء عملاء (حسب طلب السوق).

**القرار متروك للمالك: أي بند يُنفذ أولاً.**
