# ذرية تعديل عمولة الموظف

كان تعديل مبلغ العمولة يستدعي الإلغاء ثم إنشاء الاستحقاق الجديد بكتابتي حالة منفصلتين. لو رُفض إنشاء البديل بعد الإلغاء — مثلاً لغياب مصدر العمولة أو توقف الموظف أو مبلغ غير آمن — بقي الإلغاء وحده. يُبنى الآن مستند الإلغاء وقيده والاستحقاق البديل وقيده أولاً، وتُمرَّر جميعها إلى حارس الدفتر وتحديث الحالة في كتابة واحدة. يظل تاريخ العمولة القديمة كما هو، بينما يحمل القيدان والعمولة البديلة تاريخ يوم التصحيح ووقت تسجيله، ولا يعدل القيد القديم بصمت.

يُرفض المبلغ غير الآمن وتاريخ أصل غير صالح أو مستقبلي ومصدر مفقود أو موظف موقوف. تُحجب أيضاً العمولة التي لها تسوية مرتجع أو فاتورة لها مرتجع، لأن إعادة احتساب نسبة المرتجع مع عمولة بديلة لم تُثبت. هذه حماية محافظة، وليست مساراً لتصحيح تلك الحالات. اختبار المستودع يشهد تحديث حالة واحداً ويرفض ذرّياً حالة سنة مقفلة أو بيانات غير مؤهلة؛ لا يضمن ذلك نجاح تخزين دائم أو إغلاق نافذة/تزامن أجهزة. واجهتا التعديل والإلغاء لا تستخدمان قفل الترحيل الجديد ولا تاريخاً اختيارياً؛ ما زال تدقيق الفرع والصلاحيات والأصل لكل المسارات التاريخية مطلوباً. بقية النماذج لم تكتمل.

التحقق: 34 اختباراً موجهاً وبوابة العمولات 25 وverify 351/351 والمصفوفة 43/43 والأنواع وlint. لم يُعَد تشغيل الاختبار الشامل بعد هذا التعديل.
