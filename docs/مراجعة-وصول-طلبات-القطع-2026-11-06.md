# وصول طلبات القطع المرتبطة بأمر الشراء — 2026-11-06

أثبت اختباران قبل الإصلاح أن إغلاق أمر شراء كان يعلن آلياً وصول طلب قطعة لصنف آخر، أو يعلن وصول طلبات يفوق مجموع كميتها مستلم الأمر. أصبح الإعلان الآلي مشروطاً بأن يغطي مستلم الصنف مجموع الطلبات المرتبطة غير الملغاة لذلك الصنف؛ عند تعذر إثبات الكمية أو وجود بيانات غير صالحة تبقى الطلبات معلقة ولا يُختار عميل أولاً دون قاعدة تخصيص. ينطبق الحارس أيضاً على الاستلام القديم. تبقى الطلبات الملغاة خارج المجموع، وتستمر الحماية السابقة للوصول اليدوي والتسليم وإعادة فتح الوصول الآلي عند المرتجع.

اختبارات موجهة: 46 اختباراً في 5 ملفات، وtypecheck وlint وبوابة أمر الشراء ناجحة؛ أعيد توليد مصفوفة المحرك. لا تُعدَّل طلبات تاريخية أُعلنت وُصولها خطأ تلقائياً.

## حد مهم

هذه مقارنة بكميات الأمر المستلمة، وليست حجز مخزون أو تخصيص دفعات/سيريالات للعملاء. قد يكون بعض المستلم بيع أو استُخدم لاحقاً؛ يجب تأكيد توافر القطعة الفعلي قبل إخطار العميل أو التسليم. كما قد تبقى طلبات مرتبطة بأوامر قديمة مغلقة أو متناقضة بحاجة لمراجعة يدوية. لم تُختبر بيئة عميل أو تزامن نوافذ حقيقي.
