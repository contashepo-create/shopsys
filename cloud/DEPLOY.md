# المرحلة ⑥ — النسخة السحابية على Cloudflare Pages (جاهزة، النشر بقرار المالك)

> **القاعدة الثابتة:** كل الكود هنا جاهز ومُختبر محلياً، لكن **لا يُنشر شيء إلا
> بقرار صريح من المالك** — كما اتُّفق في خطة المراحل.

## ما الذي يُنشر؟

نسخة **الواجهة بالمتصفح** من «تَحَكَّم» على Cloudflare Pages: رابط عام يفتح
التطبيق كاملاً (الأصناف، الفواتير، القيود، التقارير، الكاشير…) ويعمل مباشرة
في المتصفح بلا تثبيت.

## الصدق التقني — اقرأه قبل النشر

| | نسخة الويب (Cloudflare) | نسخة سطح المكتب (EXE) |
|---|---|---|
| بيانات المتجر | تخزين **المتصفح على جهاز المستخدم** — لا تُرفع لأي سيرفر | قاعدة SQLite **مشفرة** AES-256-GCM |
| مسح بيانات المتصفح | يمسح البيانات (النسخ الاحتياطي مسؤولية المستخدم) | القاعدة ملف مستقل لا يمسحها شيء |
| الطباعة الصامتة وتعدد الطابعات | لا — حوار الطباعة الاعتيادي فقط | ✓ |
| إرسال المستندات PDF عبر واتساب | لا (رسالة صادقة داخل التطبيق) | ✓ |
| التحديث التلقائي | بتحديث النشر نفسه (فوري للجميع) | ✓ electron-updater |
| نسخ قاعدة البيانات اليومية | نسخ JSON يدوية من صفحة النسخ الاحتياطي | ✓ مزدوجة تلقائية + نقل السر بين الأجهزة |
| بوت التليجرام للنسخ | ✓ (يعمل من المتصفح) | ✓ |

**المزامنة بين الأجهزة عبر السحابة ليست في هذه المرحلة** — كل متجر بياناته
محلية عند مستخدمه. أي خدمة سحابية مستقبلية (حسابات/مزامنة) تحتاج قراراً
ومراجعة أمنية صريحة من المالك أولاً، وهي مرفوضة ضمنياً في هذه المرحلة.

## خطوات النشر (بيد المالك)

### الطريقة الأولى: أوامر مباشرة (أسرع)

```bash
# مرة واحدة على جهازك
npm install -g wrangler
wrangler login          # يفتح صفحة Cloudflare للموافقة

# من جذر المستودع
cd app && npm install && npm run build
cd .. && npx wrangler pages deploy app/dist --project-name tahakom
```

أول نشر يسأل عن إنشاء المشروع — أجب بنعم. ستحصل على رابط
`tahakom-xxxx.pages.dev` (يمكن ربط دومين خاص لاحقاً من لوحة Cloudflare).

### الطريقة الثانية: ربط المستودع (تحديث تلقائي بكل دفعة)

1. لوحة Cloudflare ← Workers & Pages ← Create ← Pages ← Connect to Git.
2. اختر مستودع `contashepo-create/shopsys`.
3. إعدادات البناء: **Build command:** `npm run build` · **Output:** `dist`
   · **Root directory:** `app`.
4. كل دفعة للفرع الرئيسي تنشر النسخة تلقائياً.

ملف `cloud/wrangler.toml` جاهز لمن يفضل wrangler — لا يحتوي أي خدمة
سحابية (لا Functions ولا KV ولا D1) بالتصميم.

## قبل النشر — قائمة تحقق

- [ ] التأكد أن إصدار `app/package.json` هو المراد نشره.
- [ ] `npm run verify:all` أخضر محلياً من جذر `app/`.
- [ ] تجربة `app/dist` محلياً: `cd app && npm run preview` — افتح الرابط
      وتأكد أن التطبيق يعمل كاملاً بالمتصفح.
- [ ] قرار المالك الصريح بالنشر (هذه الوثيقة لا تنشر شيئاً بنفسها).

## كلفة التشغيل

Cloudflare Pages: مجاني حتى 500 طلب/دفعة شهرياً للفريق، وعرض النطاق
غير المحدود للزوار — نسخة الواجهة الثابتة (ملفات HTML/JS/CSS) لا تستهلك
أي حوسبة سحابية، فلا فاتورة مفاجئة.
