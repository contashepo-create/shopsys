# خطة التطوير الشاملة للواجهة والتجربة — 2026

> **حالة الوثيقة**: اقتراحات للمراجعة — **لم يُنفَّذ منها شيء في كود التطبيق**.
> ما نُفِّذ فعلاً هو قسم «الإصلاح المباشر» فقط (مذكور في آخر الوثيقة للتوثيق).
> لا يبدأ تنفيذ أي بند هنا إلا بموافقتك على رقمه.

الفلسفة الحاكمة: **بنية نوافذ سطح المكتب (C#/MDI) + روح Apple في الحركة والوضوح**.
النافذة وحدة عمل مستقلة لها هوية وذاكرة، والحركة تشرح ما حدث ولا تُبهر، والشاشة
هادئة والمعلومة المهمة وحدها هي البارزة.

## ١) تبسيط الفاتورة ومواكبتها — «فاتورة بثلاث ضربات مفاتيح»

| # | الاقتراح | المشكلة اليوم | الأثر المتوقع |
|---|---|---|---|
| ١-أ | **شريط أوامر واحد ذكي (Command Bar)** أعلى الفاتورة يتغيّر محتواه حسب السياق (مسودة/مرحَّلة/معدَّلة) بدل ٦ أزرار ثابتة | ٦ أزرار دائمة أغلبها غير صالح في أغلب الحالات | تقليل الضوضاء ٤٠٪ ووضوح الخطوة التالية |
| ١-ب | **وضع «مركَّز» (Focus Mode)** بمفتاح واحد: تختفي اللوحات الثلاث ويبقى الجدول بملء النافذة أثناء إدخال البنود، وتعود عند الحفظ | إدخال ٢٠ بنداً في جدول ٥ سطور متعب | إدخال أسرع للفواتير الطويلة |
| ١-ج | **خط زمني للفاتورة** (مسودة ⇐ محفوظة ⇐ مرحَّلة ⇐ محصَّلة) شريط أفقي صغير أعلى المستند | الحالة اليوم نص في التذييل | فهم فوري لموقع الفاتورة |
| ١-د | **الملخص اللاصق**: «الإجمالي + المتبقي» يلتصق أسفل النافذة عند التمرير في الفواتير الطويلة | الإجمالي يغيب عند التمرير | يقظة دائمة للرقم الحاسم |
| ١-هـ | **الإدخال بالسطر الواحد (Smart Line)**: كتابة `أرز*3@65-5%` في خلية الاسم تملأ الصنف والكمية والسعر والخصم دفعة واحدة | ٤ توقفات لكل بند | سرعة الكاشير المحترف |
| ١-و | **لوحة «الأخطاء قبل الترحيل»**: قائمة مصغَّرة بالمشاكل (مخزون سالب · سعر تحت التكلفة · تجاوز حد ائتمان) مع قفز لكل مشكلة | الرسائل تظهر واحدة عند الترحيل | لا مفاجآت لحظة الحفظ |
| ١-ز | **قوالب فواتير** (أطراف متكررة/سلال ثابتة): زر «ابدأ من قالب» | إعادة إدخال يومية | توفير دقائق يومياً |
| ١-ح | **تفريق بصري بين وضع القراءة ووضع التحرير**: المرحَّلة تُعرض كمستند مطبوع نظيف وتحتاج «تعديل» صريحاً | الفاتورة المرحَّلة تبدو قابلة للكتابة | حماية من التعديل بالخطأ |

## ٢) اختصارات لوحة المفاتيح — تشغيل كامل بلا ماوس

**المبدأ**: لا أمر في الفاتورة إلا وله مفتاح، ولوحة مساعدة واحدة تكشفها كلها.

| المفتاح | الأمر | ملاحظة |
|---|---|---|
| `F2` | فتح/تبديل الطرف (عميل/مورد) | يفتح المنتقي مباشرة |
| `F3` | البحث عن صنف (المنتقي) | من أي مكان في الفاتورة |
| `F4` | تبديل النمط (مبسط ⇄ بيع مباشر ⇄ ربحية ⇄ متقدم) | دائري |
| `F7` | لوحة التحصيل (تركيز على المبلغ) | |
| `F8` | حفظ مسودة | قائم اليوم |
| `F9` | حفظ وترحيل | قائم اليوم |
| `Ctrl+Enter` | ترحيل وطباعة فوراً | |
| `Ctrl+D` | تكرار السطر الحالي | |
| `Ctrl+Backspace` | حذف السطر الحالي مع تراجع (Undo) | |
| `Alt+↑/↓` | نقل السطر لأعلى/أسفل | |
| `Ctrl+K` | **لوحة الأوامر** (Command Palette): أي أمر أو شاشة أو عميل بالكتابة | الأهم |
| `Ctrl+/` | **خريطة الاختصارات** حسب الشاشة الحالية | |
| `Ctrl+Alt+W / 1..9 / M / ↑ / Q` | إدارة النوافذ | **منفَّذ فعلاً** |
| `Alt+←/→` | التنقل بين حقول الترويسة | |
| `Esc` | تراجع سياقي: يغلق المنتقي ⇐ ثم يخرج من الخلية ⇐ ثم يسأل عن إغلاق النافذة | تدرّج ذكي |

إضافات: **مؤشر وضع الكيبورد** (شارة صغيرة تُظهر آخر اختصار مستخدم لتعليم المستخدم)،
و**تسجيل ماكرو خفيف** لتكرار سلسلة أوامر متكررة (مثلاً: فاتورة نقدية لعميل ثابت).

## ٣) محاكاة بيئة C# — إدارة النوافذ

| # | الاقتراح | الوصف |
|---|---|---|
| ٣-أ | **الالتقاط بالحواف (Snap)** | سحب النافذة إلى حافة الشاشة ⇒ نصف الشاشة؛ إلى الزاوية ⇒ ربعها؛ لأعلى ⇒ تكبير. مع معاينة شفافة قبل الإفلات |
| ٣-ب | **ترتيب تلقائي** | «تجانب أفقي/رأسي/تتالي» من شريط النوافذ — تماماً كقوائم MDI في C# |
| ٣-ج | **مجموعات النوافذ (Workspaces)** | حفظ مجموعة نوافذ مفتوحة باسم («إغلاق يومية المبيعات») واستعادتها بضغطة |
| ٣-د | **ذاكرة النافذة** | كل نوع نافذة يتذكّر آخر مقاس وموضع لكل مستخدم |
| ٣-هـ | **استعادة الجلسة بعد التحديث** | فتح النوافذ التي كانت مفتوحة قبل `reload` (العيب المؤجَّل ⑨) |
| ٣-و | **نوافذ مثبَّتة (Always on top)** | دبوس في شريط العنوان لنافذة مرجعية (أسعار الصنف مثلاً) |
| ٣-ز | **سحب وإفلات بين النوافذ** | سحب صنف من نافذة «الأصناف» وإفلاته في جدول بنود الفاتورة |
| ٣-ح | **معاينة مصغَّرة في شريط النوافذ** | تمرير الفأرة فوق زر النافذة ⇒ صورة حية مصغَّرة |
| ٣-ط | **نافذة داخل نافذة بشريط تبويب** | عدة فواتير كتبويبات داخل نافذة واحدة لمن يفضّل ذلك |

## ٤) روح Apple — الحركة والوضوح والمظهر الموثوق

| # | الاقتراح | التفصيل |
|---|---|---|
| ٤-أ | **منحنيات حركة موحَّدة** | متغيرات `--ease-emphasized: cubic-bezier(.2,.8,.2,1)` و`--dur-fast:140ms / --dur-base:220ms / --dur-slow:320ms` تُستعمل في كل مكان |
| ٤-ب | **انتقال مرتبط بالمصدر** | النافذة تنفتح **من** الزر الذي فتحها (تكبير من نقطة النقر) وتنغلق إليه — لا ظهور مفاجئ |
| ٤-ج | **طبقات مادية** | خلفيات شبه شفافة مع `backdrop-filter: saturate(180%) blur(20px)` لشريط العنوان وشريط النوافذ فقط — بلا تعتيم للخلفية (قاعدتك محفوظة) |
| ٤-د | **حركة فيزيائية (Spring)** | السحب والإفلات والالتقاط بحركة نابضة قصيرة لا خطية |
| ٤-هـ | **تغذية راجعة دقيقة** | ارتداد خفيف عند رفض قيمة، وميض أخضر عند الحفظ، واهتزاز أفقي عند خطأ الترحيل |
| ٤-و | **تدرّج بصري صارم** | ثلاثة أوزان فقط للنص وثلاثة مستويات للظل — إزالة التنافس البصري |
| ٤-ز | **أيقونية موحَّدة** | مقاس وسماكة واحدة لكل الأيقونات (`1.5px`) وإزالة الإيموجي من الأماكن الرسمية |
| ٤-ح | **حالات فارغة مصمَّمة** | رسم توضيحي + جملة + زر إجراء واحد لكل جدول فارغ |
| ٤-ط | **وضع داكن حقيقي** | تدقيق التباين (AA) على كل الشاشات لا مجرد قلب الألوان |

## ٥) إعادة هيكلة النوافذ المنبثقة

| # | الاقتراح | الوصف |
|---|---|---|
| ٥-أ | **هيكل موحَّد لكل نافذة** | ترويسة (أيقونة + عنوان + وصف + أزرار نافذة) · جسم قابل للتمرير · تذييل أوامر ثابت — مكوّن واحد `WindowShell` يمنع الاختلافات |
| ٥-ب | **أربعة أنماط فقط** | `نافذة عمل` (كاملة) · `لوحة جانبية` (Sheet منزلقة للتفاصيل السريعة) · `منبثق مرتبط` (Popover صغير بجانب العنصر) · `شريط تأكيد` (Inline bar بدل نافذة سؤال) |
| ٥-ج | **إلغاء نوافذ التأكيد المزعجة** | الحذف يتم فوراً مع **شريط تراجع** ٧ ثوانٍ (نمط iOS/Gmail) بدل «هل أنت متأكد؟» |
| ٥-د | **الحفظ التلقائي للمسودة** | النافذة لا تسأل عند الإغلاق إن كانت المسودة محفوظة تلقائياً |
| ٥-هـ | **تحميل هيكلي (Skeleton)** | بدل «جارٍ فتح النافذة…» |
| ٥-و | **ترويسة ذكية لاصقة** | عند التمرير داخل نافذة طويلة يبقى العنوان وأزرار الأمر ظاهرة مع تصغير تدريجي |
| ٥-ز | **سلسلة النوافذ (Breadcrumb)** | في ترويسة النافذة الابنة: «فاتورة مبيعات ← اختيار صنف ← أسعار الصنف» مع القفز للأم |
| ٥-ح | **حجم تلقائي بالمحتوى** | النافذة تأخذ أصغر مقاس يكفي محتواها (بحدود) بدل مقاسات ثابتة |

## مُنفَّذ فعلاً في جولة «الإصلاح المباشر» (للتوثيق)

1. **تمييز النافذة النشطة** عن الخاملة (ظل/حدّ/شريط عنوان) — لم يكن هناك أي دليل بصري على التركيز.
2. **اختصارات إدارة النوافذ**: `Ctrl+Alt+W` تنقّل · `Ctrl+Alt+1..9` قفز · `Ctrl+Alt+M` تصغير · `Ctrl+Alt+↑` تكبير · `Ctrl+Alt+Q` إغلاق، وأرقام النوافذ ظاهرة في الشريط.
3. **التحجيم من الجهات الثماني** (أُضيفت حواف الأعلى n/ne/nw).
4. **احترام `prefers-reduced-motion`**.
5. **تدقيق القيم**: ٢٩ قسماً بلا `NaN`/`undefined`/`Invalid Date`/`[object Object]`.
6. **تدقيق سلوك النوافذ**: ١٩ سلوكاً (z-order · تصغير/استعادة · تكبير · نقر مزدوج · سحب · تحجيم · اختصارات · حركة).
