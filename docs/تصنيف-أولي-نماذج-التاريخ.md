# تصنيف يدوي أولي لواجهات التاريخ

هذه جولة تصنيف استرشادية، **ليست حصراً لجميع نماذج البرنامج**. فهرس `فهرس-أولي-لنماذج-التاريخ.md` الآلي يحصي أغلفة معينة فقط ويخلط عرضاً وتعديلاً وإعداداً مع المعاملات؛ لم تُصنَّف كل صفوفه بعد. القائمة التالية راجعت العنوان ومسار الحفظ والأثر الظاهر في المصدر، ولا تعني أن هذه العمليات صالحة للإدخال بأثر رجعي دون تصميم واختبارات للتسلسل والفترات والتزامن.

| النموذج / مسار الحفظ | التصنيف والقرار | الحالة |
|---|---|---|
| فاتورة بيع `postSale` وفاتورة شراء `postPurchase` والشراء السريع | تاريخ إصدار مالي؛ المستقبل ممنوع والسنة المقفلة مرفوضة، ويختلف عن الاستحقاق والصلاحية | نُفذ سابقاً |
| أمر تغيير مشروع `addChangeOrder` | تاريخ مستند غير مرحّل؛ وقت الإنشاء والاعتماد مستقلان، والمستقبل لا يؤجل أثر الاعتماد | نُفذ سابقاً |
| قياس حصر المشروع `saveProjectSurvey` | تاريخ قياس غير مالي، ليس تاريخ كل الكميات السابقة | نُفذ سابقاً |
| دفعة العميل `receiveClientAdvance` | تاريخ تحصيل وقيد مع ترتيب استرداد الدفعات؛ الماكينة يوم التسجيل | نُفذ سابقاً |
| إصدار مستخلص `addProjectExtract` | تاريخ فاتورة وقيد وضريبة وتسلسل كميات ومقدمات؛ لا يجوز خلطه بوقت التسجيل | نُفذ سابقاً مع حارس تعديل المستخلص المؤرخ سابقاً |
| تحصيل محتجز `releaseRetention` | تاريخ تحصيل وقيد، والإقفال يحصل وقت التسجيل؛ حماية رصيد الأصل والفرع وتسلسل المستخلصات والماكينة | نُفذ في هذه الجولة |
| صرف داخلي `postConsumption` | حركة مخزون وقيد تكلفة؛ تاريخ الحركة يجب أن يُصمم مع تاريخ التكلفة والرصيد والموافقة | مطلوب؛ لا يكفي حقل واجهة |
| إتلاف مخزون `postWastage` | حركة مخزون وقيد تكلفة؛ يلزم فحص تواريخ الدُفعات والصلاحية والتكلفة والموافقات | مطلوب؛ لم يُنفذ |
| تحويل مخزني `postTransfer` | حركة مخزون غير مالية؛ يحتاج تاريخ حركة مستقل مع منع إحداث ترتيب مخزون تاريخي غير صحيح | مطلوب؛ لم يُنفذ |
| إذن مواد المشروع `issueMaterials` | حركة مخزون وتكلفة مشروع؛ مراجعة تسلسل الصرف وتكلفة المخزون وتوقيت المستخلصات والموافقة | مطلوب؛ لم يُنفذ |
| عملية المحافظ `postWalletService` | تمويل وتحصيل وضريبة وهامش ودين؛ يوجد وسيط تاريخ في المخزن لكن الواجهة لا تمرره. يلزم حراسة التواريخ والماكينة والذمة والخزائن والقفل قبل إظهاره | مطلوب؛ لم يُنفذ |
| صرف سلفة الموظف `grantEmployeeAdvance` | تحصيل/صرف وذمة موظف؛ تاريخ وقيد وتأثير الاسترداد والمسير والخزينة | مطلوب؛ لم يُنفذ |
| سداد سلفة نقدي `repayEmployeeAdvance` | تحصيل وتخصيص لاسترداد السلفة؛ يلزم منع تقديم السداد على أصله أو قلب ترتيب التخصيص والمسير | مطلوب؛ لم يُنفذ |
| خصم/جزاء الموظف `addEmployeeDeduction` | استحقاق يؤثر في المسير؛ يلزم تحديد الفرق بين تاريخ الجزاء والتسجيل وتوقيت الاستقطاع | مطلوب؛ لم يُنفذ |
| استحقاق عمولة الموظف `addStaffCommission` | قيد استحقاق مرتبط بالمصدر والتسوية؛ يجب فحص تاريخ المصدر والصرف والعكس | مطلوب؛ لم يُنفذ |
| تعديل/إلغاء عمولة | إجراء عاكس تدقيقي، لا يُفترض أن يكون تاريخ المستند الأصلي قابلاً لإعادة الكتابة | يحتاج تصميم مسار تصحيح، لم يُنفذ |
| طلب اعتماد ومسار الموافقات | حدث توقيع/صلاحية يُختم وقتياً، لا يسمح تقويم حر بتزوير وقت الموافقة؛ قد يُطلب تاريخ المستند الأصلي في نموذجه منفصلاً | لا يُضاف تاريخ معاملة لمجرد غياب الحقل |
| تصدير/استيراد مفتاح الاسترداد، ومرفقات المستند، وقوالب الطباعة، ومسودات الفاتورة | أدوات أمن/ملفات/إعداد أو اختيار، وليست بذاتها معاملة مالية جديدة | لا تاريخ ترحيل مستقل هنا؛ راجع تاريخ المستند الأصلي عند إصداره |
| اختيار الفاتورة الأصلية للمرتجع | خطوة اختيار وليست إصدار المرتجع نفسه | لا تاريخ على نافذة الاختيار؛ نموذج المرتجع وحراسه يحتاجان مراجعة منفصلة |
| استيراد الموظفين / تحرير بيانات موظف | بيانات مرجعية؛ تاريخ الالتحاق موجود في محرر الموظف، وليس تاريخ قيد | لا يستلزم تاريخ معاملة لكل تغيير بيانات |

كل نموذج لم يرد هنا أو ورد بعنوان ديناميكي في الفهرس **غير مصنّف بعد**. النماذج التي حُددت أعلاه «مطلوبة» لا تُعتبر منجزة. يلزم أيضاً تدقيق الصفحات والمعالجات خارج أغلفة الفهرسة، وحالة منطق الفروع والاعتماد والسنوات لكل مسار قبل إتاحة الماضي؛ وجود تاريخ في النوع أو في حقل غير مستخدم لا يثبت صحة الترحيل.

## توسعة مراجعة المرشحين عالية الأثر

هذه الإضافات تحدد نوع العمل والإجراء المطلوب؛ كلمة «يلزم» تعني غير منفذ بعد، لا أن المحرك يدعم الرجوع الآمن. العنوان الديناميكي حُدد من تعبير JSX وزر الحفظ، لكنه قد يتضمن مكونات أو وظائف مشتركة تحتاج تدقيقاً إضافياً.

| الواجهة والإجراء | القرار والأثر الذي يلزم حراسته |
|---|---|
| `InsuranceProvidersSection`: رد مؤمن كلي/جزئي وصرف رد لجهة التأمين | حركات رد مرتبطة بالفاتورة والمطالبة والدفع؛ يلزم فصل تاريخ الإشعار عن وقت التنفيذ والتحقق من الأصل والتسوية والضريبة والفروع. |
| `CarsPage`: شراء سريع / بيع سيارة / بيع أمانة | شراء أو فاتورة أو بيع لصاحب السيارة مع مخزون وضريبة وذمم؛ يلزم مراجعة تواريخ كل مسار والعمولات والأصل وقيود الفروع. |
| `CarsPage`: تجهيز سيارة أو تأجير / استلام الأمانة | مصروف أو عقد/حركة أمانة تشغيلية؛ يحتاج التاريخ حسب مسار القيد والمستند لا مجرد تاريخ البيع. |
| `ContractingDepthPages`: شهادة باطن أو دفعة أو دفعة مقدمة | استحقاق ودفع والتزام مرتبط بعقد باطن؛ يلزم حماية تاريخ الأصل والدفعة والاسترداد والمحتجز والسنة المالية. |
| `ContractingDepthPages`: عقد باطن، بند BOQ، عامل اليومية وتعديلهم | عقد أو بيانات مرجعية؛ تاريخ العقد أو أوقات السجل تخضع لمعناها لا لحظر تواريخ الفواتير، ويلزم فحص ما ينتج عنه من دفعات. |
| `CustodyPage`: فتح عهدة وتمويل ومصروف وتسوية | أرصدة عهدة وخزينة وتكاليف وتسويات؛ يتطلب التاريخ حراسة التسلسل حتى لا تُنسب مصروفات إلى تمويل لم يكن موجوداً. |
| `EmployeesPage`: مسير مجمع وقسائم | فترة المسير ليست بالضرورة تاريخ الاستحقاق أو الصرف؛ لا يستبدل أحدها بآخر، ويلزم تصميم آثار الاستقطاعات وتواريخ القيود. |
| `EquipmentPage`: مصروف تشغيل معدة | مصروف وخزينة وربما ارتباط بعقد أو مشغل؛ يلزم ربط تاريخ المستند بالقيد والتسلسل والفرع. |
| `ClinicPages`: تحصيل من ملف مريض أو رد زيارة | قبض أو رد مرتبط بالذمة والأصل؛ يلزم تاريخ وقيد وتحقق من التسوية والأصل قبل إتاحة الماضي. |
| `LabPages`: طلب تحاليل جديد | قد يجمع طلباً طبياً وتحصيلاً وضريبة؛ تاريخ الطلب الطبي ووقت العينة وتاريخ الفاتورة مفاهيم مختلفة، ويلزم فحص المسار والنتائج والمطالبات. |
| `LabPages`: رفض العينة وإبلاغ القيمة الحرجة | أحداث طبية وتدقيقية تحتاج وقت حدوث/إبلاغ موثوقاً؛ لا يجوز استبداله بتقويم معاملة مالية عام. |
| `RealEstatePages`: إنشاء عقار أو وحدة / بيع عقار أو وحدات | قد يتضمن شراء أو بيعاً وقيوداً وذمة وعقداً؛ يلزم تحديد تاريخ الأصل والفاتورة والقيد والتسليم والتسويات لكل مسار. |
| `RealEstatePages`: سداد المالك / مصروف صيانة / إنهاء عقد | تسوية نقدية أو مصروف أو إقفال عقد؛ يلزم حماية أصل الالتزام والتحصيل والعهدة والتسلسل وقيد التصحيح. |
| `RentalContractsPage`: فتح عقد أو إصدار فاتورة إيجار دورية | تاريخ العقد وفترة الإيجار وتاريخ الفاتورة الضريبية والاستحقاق متميزة؛ يلزم منع مستقبل تاريخ الفاتورة ومراجعة قيدها والتحصيل والماكينة دون منع فترة إيجار مستقبلية. |
| `TripsPage`: فاتورة نقلة / مصروف مرتبط بها | فاتورة وضرائب وتحصيل، أو مصروف مرتبط؛ يجب تدقيق تاريخ الفاتورة والقيد والصرف والفرع والتسوية، لا الخلط بين وقت رحلة وتاريخ فوترة. |
| `SaleReturnsPage` / نموذج مرتجع `PurchaseReturnsPage` | إشعار أو مرتجع مخزني/مالي متعلق بالأصل؛ يلزم تاريخ صحيح بعد الأصل وحماية الضريبة والرصيد ورد الماكينة والتسويات. اختيار الفاتورة وحده ليس إصداراً. |
| `TreasuryPage`: تحويل بين خزائن | حركة نقدية ذات تاريخ وقيد وطرفين؛ يلزم تدقيق الفرع والرصيد التاريخي لكل حساب وصلاحية المستخدم. |
| `SettlementsPage`: مقاصة العملاء والموردين | تسوية غير نقدية؛ تاريخها لا يسبق أصل الذمتين، ويلزم حماية التوزيعات والفرع والقيد. |
| `ShiftsPage` وفتح وردية نقطة البيع | فتح/إغلاق وتوثيق فرق وردية أحداث فعلية، فلا تُعاد كتابتها بتاريخ حر. قيد تسوية الفرق يحتاج مراجعة مستقلة دون تزوير وقت الوردية. |
| `RestaurantOrdersPage`: تسوية الطلب / تقسيمه ودمجه | التسوية فاتورة وتحصيل ووردية؛ التقسيم والدمج إجراءات تشغيلية. يلزم فصل التاريخ الفعلي وقيود إعادة التجميع عن تاريخ الفاتورة وضريبتها. |
| `PaymentTerminalsPage`: تسوية ماكينة | تسوية استناداً إلى عمليات ومراجع مزود مؤرخة؛ لا يجوز إرجاع وقت عملية ماكينة بلا إثبات. تاريخ التسوية نفسه يحتاج تدقيق المصدر والقيد والفترة. |
| `FxCollectModal` / `FxTreasuryTab`: تحصيل أجنبي وتصحيح ساق العملة | التحصيل مرتبط بسعر صرف وسند وأصل؛ التصحيح سجل مستقل وأثره يحتاج إثباتاً، لا تغيير تاريخ الأصل بصمت. |
| `SerialsPage`: ربط سيريال قديم / استبدال جهاز | الربط تصحيح أدلة تاريخية، والاستبدال مشتريات/بيع وحركة سيريال؛ يلزم منفصل للتدقيق وحراسة المخزون والفاتورة. |
| `SupportPage`، قوالب الأسعار والطباعة، الحسابات والصلاحيات، بيانات عميل/مورد، مستندات المرفقات | إعداد أو بيانات مرجعية أو اتصال، وليست في ذاتها معاملة ترحيل جديدة؛ إن احتاجت تاريخ سريان أو تدقيق فهو مستقل عن تاريخ القيد. |
