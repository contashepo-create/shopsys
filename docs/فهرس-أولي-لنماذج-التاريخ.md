# فهرس آلي أولي لواجهات الإدخال

نتيجة تحليل شيفرة JSX: 195 غلاف إدخال منها 152 بلا input من نوع date أو datetime-local داخل الغلاف نصياً. هذا ليس حصراً نهائياً للفورمات التي تحتاج تاريخ معاملة: قد يكون التاريخ داخل مكوّن مستورد، أو حقل آخر خارج الغلاف، وقد تكون النافذة فلتراً أو إعداداً أو تحصيلاً لا يحتاج تاريخاً. ولا يحصي الواجهات التي لا تستخدم هذه الأغلفة، ولا يميز تاريخ استحقاق أو صلاحية عن تاريخ المعاملة. يجب مراجعة كل مرشح مع مسار الحفظ والأثر المالي يدوياً قبل التغيير.

الأغلفة الممسوحة: Modal وSheetPanel وInvoicePOSFrame وform. يكرر الفهرس بعض المكونات المتداخلة. شُغّل من app بالأمر node scripts/inventory_date_forms.mjs.
